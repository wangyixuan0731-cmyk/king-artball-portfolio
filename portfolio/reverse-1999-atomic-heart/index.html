CORE FINDING

本次联动的首周流水和下载量均弱于《刺客信条》联动，首周流水也低于周年庆版本。原子之心IP受众相对有限、周年庆舆论造成玩家流失，使联动未形成更广泛的拉新；但双生舞伶补齐术具队主C、阶梯礼包与多款直购衣着，又有效承接了仍在游玩家的补队和付费需求。

01

DATA PERFORMANCE

联动抬升存量付费，但没有恢复拉新体量

从首周表现看，本次版本流水与下载量均低于《刺客信条》联动：首周流水下降14.6%，首周下载下降27.7%；与三周年版本相比，流水下降24.2%，下载量则接近，差距为4.4%。首日游戏畅销榜排名第14，也弱于《刺客信条》联动的第11名。

排名在7月29日回落至第89，第8日进一步降至第101，首周衰减轨迹与《刺客信条》联动的11→87相近。表现更适合概括为：联动并未带来更强的新增和回流，但版本内容对存量玩家的付费转化仍然有效。

拉新端

原子之心IP受众相对有限，叠加周年庆舆论事件后的玩家流失，联动覆盖面没有转化为更高下载。

付费端

双生舞伶补齐术具队主C，多款联动衣着直购上新，促使仍在游玩家为补队、角色和外观继续消费。

02

WELFARE PACKAGE

约104抽福利，降低联动参与门槛

福利结构与《刺客信条》联动相近：登录赠送月卡、限定十连、10天签到获得10个独一律，并免费发放四星联动角色诺拉。原子之心版本还增加衣着优惠券和多项登录材料，社区统计零氪约可获得104抽，整体反馈较正向。

征集追加特惠延长了长线抽取目标：首次达到100抽后，每60抽除可额外自选联动角色外，还可以自选一名六星角色。衣着侧则通过任意衣着减390粹雨滴、当季惠选28元或680粹雨滴的折扣，兼顾抽卡和外观消费。

03

MONETIZATION

阶梯礼包把两类抽卡需求装进同一条付费路径

版本新增“金线的馈奉”阶梯礼包，6元、18元、30元三档依次解锁，后一档必须在购买前一档后开放。每档同时包含联动池与常驻池抽卡道具，并配套养成材料，使小额付费和月卡玩家不必在“抽联动角色”与“补常驻角色”之间二选一。

“银色双子星”保留45元与98元两档，并将部分抽数放在取得双生舞伶后追加发放：已经出货的玩家会继续补塑造，尚未取得角色的玩家则会为了提高礼包性价比继续下池。100、160、220、280抽节点还可自选当期角色或箱装印象，进一步承接补角色与补塑造需求。

04

CHARACTER & OUTFITS

双生舞伶补齐术具队，也把队友缺口变成后续需求

双生舞伶定位为术具体系主C，是首位双灵感六星角色：拥有星／岩双灵感，可同时装备两件专属心相，大招会清算两类能量。两件专属心相都能通过版本内容获得，0塑即可完成核心循环，降低了主C本体的养成阻力。

理想配队为双生舞伶＋回声谣＋珐琅眼＋小瑞安侬。这些队友集中在近期版本推出，已有核心辅助的玩家容易形成“只差主C”的补队心理；缺少关键辅助的玩家，则会产生后续复刻需求。版本同时上新4款直购衣着、1款活动免费衣着和1款BP衣着，覆盖高活跃角色、联动主角、低价高持有率角色与零氪人群。

战斗价值

高数值主C直接解决术具体系最后一个核心位置，角色与前置版本队友形成明确的售后关系。

外观价值

纸信圈儿98元、双生舞伶与玛丽安娜68元、泥鯭的士28元，价格与角色持有率、强度和视觉创新相匹配。

05

ACTIVITY LOOP

“重返切洛梅”把联动设定转化成探索循环

联动专属活动“重返切洛梅”以3826号设施为舞台，将《原子之心》的场景探索、手套升级和资料收集，转化成地图探索、解谜与战斗循环。玩家在多个地标间处理机器人失控和技术难题，消耗神经聚合物解锁并强化聚合物手套，使其在后续战斗中提供增益。

探索过程中收集的历史与角色信息会进入“公开档案”；内置小游戏“思维导图”承担解谜环节。如果卡关，玩家可以长按“暴力拆解”直接通关，保留解谜主题的同时避免进度被单一谜题阻断。

商业化结构补充

“金线的馈奉”越往后单抽折合价格越高，但同步提供更多抽卡资源和养成材料。它并非单纯追求最低单抽价格，而是通过低门槛起步、连续解锁和双池资源，促使小额付费玩家逐档完成购买。

衣着端通过优惠券和当季惠选折扣覆盖高低不同预算；角色端通过出货后返还和多档自选节点延长抽卡深度，形成福利吸引参与—低价礼包启动付费—角色队伍促成补强—外观承接额外消费的完整链路。

结论

原子之心联动版本没有复制《刺客信条》联动的拉新规模，首周流水也低于周年庆版本，但它通过高福利、术具体系主C、双池阶梯礼包和多档衣着，形成了对存量玩家更清晰的转化链路。版本的优势在于“补齐需求”设计完整，限制则在于IP受众与前序舆论共同压缩了可转化人群。

返回作品集
联动负责吸引注意，真正承接收入的是队伍补齐、分层付费与外观供给。

数据口径：iOS表现，比较对象与百分比均来自原监控报告。福利总量为报告记录的社区统计；玩家反馈与归因属于版本期观察，不作为官方事实判断。
