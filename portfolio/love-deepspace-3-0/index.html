《恋与深空》祁煜日卡3.0版本监控报告

“我氪的不是金，是我推的排面”——一次排名反弹与大盘恢复之间的差异观察。

VERSION 「破阵子」
PERIOD 8月17日—8月31日
共13天
SCOPE iOS数据表现、玩家反馈、版本活动与商业化

CORE FINDING

版本上线后将7—8月的低迷排名拉升至畅销榜第5，但首周流水与下载量均处于近一年日卡及混池的低位。核心粉丝集中冲榜带来了短期排名反弹，却没有同步带动收入、新增和大规模回游，版本仍未完全消化6.0风波后的用户流失与信任损耗。

01

DATA PERFORMANCE

排名回升，并不等于大盘恢复

祁煜3.0日卡首日进入游戏畅销榜第5、总榜畅销第9，结束了此前一段时间的排名低谷。但把排名与首周体量放在一起看，恢复程度仍然有限：首周预估流水为273.42万元，较祁煜2.0日卡首发下降63.4%；首周预估下载量为41,908次，较祁煜2.0首发下降47.6%。

下载量在8月18日达到8,204次的首周峰值，随后回落至约5,000次／日。与近一年混池相比，3.0日卡的首周流水和下载量同样偏低。由此更适合把这次表现理解为短期冲榜成功，而不是收入与新增体量已经恢复。

02

KEY ATTRIBUTION

多重争议叠加，玩家信任链路断裂

7—8月卡池投放较少，在游玩家拥有较长的资源积累时间，这为版本首日排名提供了条件；但它也意味着本次付费受到存量资源影响，不能直接视为新增付费意愿增强。与此同时，6.0版本前后的多项争议持续影响玩家对后续内容的预期。

新男主官宣与取消

在既有五位男主产能已被质疑的背景下，敖尹官宣加剧资源分配担忧；6月30日取消上线后，不支持与支持上线的玩家又分别出现退游和持续维权，两个群体均产生信任损耗。

6.0内容与人设争议

厨房区域更新中的角色行为被部分玩家认为存在OOC；前序篮球卡也因剧情与画面表达受到批评，削弱了版本间的内容承接。

文本与宣发口径

实验体编号、传统节日称谓及大陆与海外宣发差异等问题被重新讨论，进一步放大了玩家对文本审核和内容立场的敏感度。

上线时间反复

官方此前预告祁煜日卡于7月上线，客服随后回复调整至8月，最终在夏以昼月卡之后于8月下旬推出，前后口径不一致继续消耗预期。

03

RANKING MECHANISM

核心粉丝集中投入，制造榜单峰值

祁煜与秦彻的往期日卡表现相对更好，仍在游的祁煜推具备较强消费能力。经历约一个月的空池与资源储备后，这部分用户仍愿意为新日卡付费，成为首日排名的重要支撑。

社区同时出现“日卡守护大赛”等应援活动，以iOS手游端充值记录作为参与凭证，并设置手机、黄金项链等奖品。这类组织化应援能够把消费集中到短时间窗口，因此更容易体现在榜单名次上；但首周流水仍显著低于往期，说明这次表现更接近核心群体集中冲榜，而非沉默用户和退游用户大规模回归。

04

CARD & CONTENT

高饱和武将感，覆盖了角色原有锚点

卡面整体使用高饱和红色、金属纹样与强战斗特效，部分玩家将其概括为“一刀999”式网游风，认为它与祁煜此前清透、浪漫和海洋感较强的视觉印象存在差异。暖调打光同时覆盖服装、肤色与背景，也使紫色发色、蓝粉交错瞳孔等辨识锚点变得不够清晰。

社区还讨论了卡面设计与其他古风卡的相似性，以及某些角度下角色建模相似的问题。这些内容属于玩家质疑与主观反馈，不能直接等同于制作事实，但集中反映出用户对角色差异化和美术独特性的敏感程度。

  • 剧情：将军身份和完全IF线设定被部分玩家认为较通用，未能像前两张日卡一样补充祁煜既有世界观。
  • 战斗：新日卡连招、充能与节奏要求较高；无法熟练掌握多种连招时，较难稳定打出伤害。
05

ACTIVITY LOOP

每日限次，把剧情、玩法与奖励串成持续参与

主题活动以探索进度作为主线。玩家每天可探索两次，也可使用10红钻补购一次；完成探索节点后，依次解锁对话、小游戏和战斗，并在活动开启约8天后阅读完全部剧情。完成全部探索可获得限定四星卡牌。

玩法层面，固定阵容战斗承担新卡局内效果试玩；推石块小游戏提供轻量操作；完成小游戏后还会获得特殊道具并触发祁煜专属对话。限时任务产出的活动积分则进入活动商店兑换，构成日常进入—玩法体验—剧情反馈—积分兑换—核心奖励的完整链路。

商业化补充观察

版本礼包结构与往期日卡基本保持一致，并叠加七夕情侣服饰「流景扬辉」。一组礼匣包含男主和女主配套服饰各一套，通过第二组、第三组阶梯折扣促进多套购买；写真背景则以紫钻折扣价单独售卖。

服饰供给覆盖男主通用长外套、主控马面裙与改良外套等国风组合，延续版本美术主题。8月24日又叠加新一轮密约，为日卡活动后半程补充持续付费点。

结论

祁煜3.0日卡证明核心角色和核心粉丝仍具备短时间冲榜能力，但低于往期的首周流水与下载量说明，榜单反弹尚未转化为大盘恢复。版本真正需要修复的并非单一卡池强度，而是角色差异化、内容质量、产能安排与官方沟通共同构成的长期信任。
